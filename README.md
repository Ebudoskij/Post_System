# Система управління поштовими відправленнями — Лабораторна робота №2 (NoSQL vs SQL)

Цей репозиторій містить реалізацію **Лабораторної роботи №2** з дисципліни **«Сучасні технології баз даних»** на тему дослідження видів NoSQL баз даних, впровадження **Polyglot Persistence** (PostgreSQL + MongoDB + Redis) та порівняльного тестування їх швидкодії.

## Зміст та архітектура проєкту

Проєкт побудований на базі Лабораторної роботи №1 та розширений двома NoSQL базами даних різних типів:
1. **PostgreSQL (Реляційна СУБД):**
   - Транзакційне ядро системи (ACID) + **5 нормалізованих таблиць (3НФ)**, які відображають розширений паспорт посилки: `parcels`, `parcel_specifications`, `customs_declarations`, `parcel_items`, `tracking_telemetry`.
2. **MongoDB (Документо-орієнтована NoSQL СУБД — Пункти 3–5):**
   - Колекція `parcel_manifests` зберігає повний **«Цифровий маніфест та IoT-трекінг відправлення»** (`ParcelManifestDocument`) як єдиний самодостатній BSON-документ із вкладеними об'єктами специфікації, митної декларації, масивом товарів (`items[]`) та масивом подій телеметрії (`telemetryEvents[]`).
3. **Redis (Key-Value & In-Memory Data Structures NoSQL СУБД — Пункт 6):**
   - Демонструє 5 спеціалізованих структур даних у контексті поштової логістики:
     - `String + TTL` (`SETEX`, `GET`, `DEL`, `INCR`) — кешування гарячих ТТН за патерном **Cache-Aside** та лічильники популярності;
     - `Hash` (`HSET`, `HGETALL`, `HINCRBY`) — оперативна сесія кур'єра на зміні;
     - `Geo-Spatial` (`GEOADD`, `GEOSEARCH`, `GEODIST`) — пошук найближчих відділень та кур'єрів у радіусі $N$ км;
     - `Sorted Set / ZSET` (`ZINCRBY`, `ZREVRANGE`) — живий рейтинг (Leaderboard) найбільш завантажених відділень;
     - `List` (`LPUSH`, `RPOP`, `LLEN`) — черга відправки SMS/Push-сповіщень клієнтам.

## Швидкий старт (Docker Compose + Тести та Бенчмарки)

### 1. Підняття інфраструктури (PostgreSQL 17 + MongoDB 8.0 + Redis 7.4)
```bash
docker compose up -d
```

### 2. Запуск функціональних тестів Redis (Пункт 6)
```bash
./mvnw test -Dtest=RedisPostServiceTest
```

### 3. Запуск комплексного бенчмарку PostgreSQL vs MongoDB vs Redis (Пункти 3–5, 50 000 посилок)
```bash
./mvnw test -Dtest=SqlVsMongoAndRedisBenchmarkTest
```
