# Система управління поштовими відправленнями

Цей репозиторій містить проєкт бази даних та рівень доступу до даних, розроблений у рамках лабораторної роботи з дисципліни **«Сучасні технології баз даних»**.

**Виконав:** студент групи ТК-31, Будовський Єгор.

## Структура проєкту

Уся ключова документація та скрипти ініціалізації знаходяться у директорії [`./docs`](./docs). У цій папці зберігаються:
* **SQL-скрипти** — повний код для побудови бази даних (DDL, створення таблиць, індексів, тригерів, розрізів та збережених процедур) і наповнення її тестовими даними (DML).
* **Діаграма бази даних** — візуальне представлення ER-схеми у форматі `.png`.

## Інтерактивна діаграма

На додачу до статичного зображення у папці `docs`, повну та інтерактивну схему бази даних (із зазначенням усіх зв'язків, ключів та типів даних) можна переглянути онлайн:

## Стек технологій
* **СУБД:** PostgreSQL (з використанням Stored Procedures, Views, Triggers)
* **Backend:** Java 25, Spring Boot 4.0.8
* **Патерни:** Repository, Unit of Work (через `JdbcClient` без використання ORM)
